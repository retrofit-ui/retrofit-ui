features:
  - title: Schema-driven
    details: Define your data shape once in Zod or Java. retrofit-ui derives columns, fields, validation, and enum options automatically — no duplication.
  - title: Server-owned UI contracts
    details: Your server returns JSON specs describing the UI. Add a field to your schema and the form updates immediately, with no frontend deploy.
  - title: Express & Spring Boot
    details: One-line setup for Node.js/Express. Zero-config autoconfigure for Spring Boot — add the starter and your endpoints appear at /retrofit-ui.
  - title: Three view types
    details: Table view with inline editing, form view for create/edit/delete, and a markdown render view. Wire them up individually or as a workflow bundle.
  - title: Themeable
    details: Built on Shoelace web components. Override CSS custom properties to match your brand — no CSS framework conflicts.
  - title: Polyglot
    details: The SPA is language-agnostic. Any server that returns the right JSON spec gets the full UI — JS, Java, or anything else.
